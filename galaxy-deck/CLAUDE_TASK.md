# GALAXY DECK v2 — Claude 実装指示

**対象**: このブランチの `galaxy-deck/index.html`（既存のプレイ可能なゲームが入っています）。
**目的**: GAME BANKに収録できる、スマートフォン最優先の高品質な日本語カードゲームへ進化させること。
**重要**: 他のゲーム/サイト/既存の公開設定/monetizationを変更しない。メインへの直push、本番公開、既存ゲームの削除は禁止。機能ブランチで実装し、PRとテスト結果を示す。

## 現行ルール（維持・改良可）
- 3星域（太陽／月／星雲）にカードを配置する1人対CPUの6ラウンド対戦
- 19種類・26枚構成、コスト・パワー・属性・能力・スペル
- 6ラウンド後は勝った星域数優先、同点なら合計パワーで判定
- タップでカード選択→星域配置、PCドラッグ操作、効果音切り替え、ローカル戦績保存
- APIキーやログイン無し、基本的には完全ローカル動作を維持すること

## 実装優先度
P0: 既存ソースをまず静的ホストで動作させ、再現性のあるプレイテストを整備する。存在しない `icon.svg`, `manifest.webmanifest`, `sw.js` を整備するか、参照の不整合を安全に解消する。iPhone 375px/390px幅、Android 360px幅、PC 1280px幅のレイアウトを検証し、タップ不能、はみ出し、選択状態不明、終局不能、無音、コンソールエラーを修正。

P1: カード画像・背景を「銀河、星座、惑星、ホログラム」のアートディレクションで統一。20枚近いカードは属性・レアリティが一目で分かる専用イラスト/軽量SVG等を追加する。著作権を侵害する素材は使わない。カード選択、召喚、能力発動、星域決着、最終勝利の動きと音を強化。効果音はミュート可能、reduced-motionに対応。

P2: ソロ周回の動機づけを追加：バトルで獲得するゲーム内スター／カードパック開封／コレクション一覧／重複カード強化・進化（数値インフレと課金要素は控えめ）／レアリティ4段階をデータ駆動で実装。ローカルセーブ破損対策、初期化/再開導線を用意。現金・仮想通貨・リアルマネーによるランダム商品販売は実装しない。

P3: ボス戦（少なくとも3体）、チュートリアル、難易度選択。AIは合法手しか使わないこと。星域能力・スペル・エネルギーを含め勝率が極端に偏らないよう検証。

## 必須品質基準
1. 新規ゲーム、6ラウンドの勝敗、再戦、スター獲得、パック開封、進化、戦績保存・再読込が動作する。
2. 360–430pxの縦画面で文字切れ、重なり、横スクロール、ゲーム不能がない（カード手札の横スクロールは可）。
3. レアリティ・属性・パワー・必要エネルギー・効果説明を見やすく表示し、アクセシビリティとフォーカスに配慮。
4. `localStorage`が空/壊れている場合もクラッシュしない。
5. Playwright等の自動E2Eテスト + ロジック単体テストで、主要フローのPASS/FAILと残課題を報告。
6. 実装した機能だけを説明し、デモのフリをした画面や「テスト済み」の虚偽報告をしない。
7. 最後に変更ファイル、遊び方、テスト結果、スクリーンショット、PR URLを提示。

## 進め方
1. 現行 `galaxy-deck/index.html` を読み、仕様・バグを把握。
2. 既存のゲーム性を残したまま段階的に実装。
3. 一連のゲーム体験をテストしてPRを作成。
4. レビュー承認前に本番環境へデプロイしない。
